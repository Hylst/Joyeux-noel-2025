
# 🎄 Joyeux Noël 2025 - Une Expérience Numérique Féerique ✨

Bienvenue dans ce projet de carte de vœux interactive, conçu pour célébrer Noël à travers la magie du code et de l'Intelligence Artificielle.

![Aperçu](https://images.unsplash.com/photo-1544967082-d9d3fdd0627c?q=80&w=1200&auto=format&fit=crop)

## 🌟 Fonctionnalités

*   **Génération d'Ambiance par IA** : Utilisation de l'API Google Gemini pour créer des arrière-plans festifs uniques à chaque visite.
*   **Éditeur de Code Enchanté** : Une simulation ludique de déploiement de la magie de Noël.
*   **Système de Particules** : Chutes de neige dynamiques et lucioles interactives.
*   **Design Sonore Immersif** : Musique de chœur, bruitages de neige et sons magiques.
*   **Responsive Design** : Une expérience fluide sur mobile et desktop.

## 🛠️ Technologies

*   **React 19** & TypeScript
*   **Google GenAI SDK** (Gemini 2.5 Flash)
*   **Tailwind CSS** pour le style

## 🚀 Installation & Lancement

1.  Clonez le projet :
    ```bash
    git clone https://github.com/Hylst/Joyeux-noel-2025.git
    ```

2.  Installez les dépendances :
    ```bash
    npm install
    ```

3.  Configurez votre clé API :
    *   Le projet utilise `process.env.API_KEY` pour communiquer avec Google Gemini.

4.  Lancez la magie :
    ```bash
    npm start
    ```
